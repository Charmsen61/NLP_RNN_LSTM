# NLP_RNN_LSTM

## Overview

This project compares a SimpleRNN model and an LSTM model for next-word prediction using TensorFlow and Keras. The models are trained on a small text dataset and then tested on several prompts to predict the next word in a sequence.

## Objectives

- Tokenize text data
- Convert words into integer sequences
- Create input and target training pairs
- Build and train a SimpleRNN model
- Build and train an LSTM model
- Compare prediction performance between both models

## Dataset

The project uses a small custom dataset containing simple sentences about dogs, cats, birds, boys, and girls.

the dog ran across the street
the cat sat on the mat
the dog chased the cat
